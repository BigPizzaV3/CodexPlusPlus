FEATURES · 功能矩阵

一个管理工具，管到底

从供应商配置到界面增强，从会话管理到桌宠挂件。所有增强可单独开关，关掉总开关，供应商与启动管理照常可用。

01

供应商自由切换

官方登录、官方登录 + API、纯 API 与聚合供应商。故障转移在多个供应商间失败切换，模型聚合按模型固定成员；支持 Responses / Chat Completions 协议转换、模型测试与 Provider Doctor。

02

每个模型，各有空间

按模型设置上下文窗口与自动压缩阈值，生成独立 model_catalog_json，Codex 按当前模型识别窗口；支持模型元数据导入，按供应商选择 MCP、Skill 和 Plugin。

03

会话管理更省心

本地会话扫描、删除与撤销、批量管理、Markdown 导出、Token 历史、项目移动和线程 ID，历史会话想找就找、想删就删。

04

拓展你的工作区

浏览与管理社区用户脚本，按需添加模型选择、用量统计等能力；另有 MCP、Skill 与 Codex 插件管理，也可以写自己的脚本热重载调试。

05

输入与阅读，都顺手

语音输入、粘贴修复、会话宽度、滚动位置恢复、下一步建议、回答大纲，还有刚才那一手的光标打字特效。

06

同一台电脑，多个 Codex

为每个供应商身份启动相互隔离的 Codex 实例：独立配置、会话和用户数据目录，可同时运行，集中列表里单独重启或结束。

07

用量状态栏

输入框下方实时显示生成速度、缓存命中率与上下文占用；数据取自本机 Codex 会话记录，口径与 Codex 一致，默认开启。

08

用量可见，也有陪伴

用量挂件与桌宠角色：Token 统计、任务状态与预算提醒，可拖动、缩放、换皮肤与自定义图片，认真工作也有点趣味。

09

微信连接

扫码连接本机 Codex，每个联系人映射到独立会话，并可配置允许访问的微信用户。出门在外，也能远程派活。

10

一句话，派给子 Agent

在当前 Codex 对话中委派 DeepSeek Harness（dsh）、Claude Code 或另一个 Codex，由对应 CLI 执行，再把结果带回原对话。管理器可配置默认 Agent、CLI 路径和模型；点名时交给指定对象。

11

API Key 也能用原生 Fast

纯 API Key 模式恢复 Codex 的原生 Fast 开关，沿用 Standard / ⚡ Fast 控件。默认关闭，模型需声明 Fast（priority）支持；实际可用性与计费由供应商决定。

12

请求避震

模型容量/过载错误（server_overloaded、server_is_overloaded、at capacity）在代理层自动退避重试，不再频繁打断 Codex 会话。状态行显示请求阶段、模型、耗时、重试次数与上一次失败原因；流式避震保留实时输出，整段缓冲避震则在任何时点吸收过载。

GETTING STARTED · 快速上手

Codex++ 配合官方 Codex / ChatGPT 桌面应用使用，首次启动前请确认已安装对应的官方应用。

01

前往 GitHub Releases：Windows 选 *-windows-x64-setup.exe，macOS（Apple Silicon / Intel）选 *-macos-universal.dmg，拖入「应用程序」。

FAQ · 常见问题

先问，先答

启动后，为什么没有 Codex++ 菜单？

确认是在 Codex++ 界面中点击「启动」打开的官方应用。打开管理工具的「安装维护」与「关于」页面，检查应用路径、启动状态和诊断日志。

切换供应商后，请求为什么失败？

先在供应商详情中运行模型测试或 Provider Doctor，确认协议、Base URL、Key 与模型匹配。纯 API 和官方登录 + API 使用不同的认证位置，不要手工复制两种模式的 auth.json。

开启原生 Fast 后，为什么仍然看不到开关？

先确认已经保存，并通过 Codex++ 重启 Codex。当前模型还需要声明 Fast 服务等级：在「供应商配置」中打开该模型的配置，设置「Fast（priority）支持」，保存模型与供应商后重启。请按供应商实际能力声明；此功能只恢复客户端入口，服务限制与计费仍以供应商为准。

增强功能可以关闭吗？官方应用更新后还能用吗？

可以分别关闭，也可以关闭增强总开关。Codex++ 依赖官方桌面应用的页面结构、CDP 和本地数据格式；官方应用更新后，部分功能可能需要跟随适配。修改供应商配置或会话数据前，请保留备份。

配置、会话和日志存在哪里？

设置了 CODEX_HOME 时，Codex 主目录以该变量为准；否则使用 ~/.codex。API Key 只保存在本机，提交反馈前请隐藏密钥与认证信息。
