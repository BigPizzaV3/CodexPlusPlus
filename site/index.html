PROVIDERS · 网关与直连

供应商，随你接

网关让所有 Agent 共用一份供应商池；Codex 原来的四种直连接法照旧可用，两种模式随时切换。

网关

本地网关同时服务 Codex、Claude Code 与 Grok，所有接入的 Agent 共用一份供应商池：按模型名选供应商，Key 轮换与冷却，出错自动换下一家；ChatGPT、GitHub Copilot、SuperGrok 订阅也能登录进池。

  • 一份供应商池，所有 Agent 共用
  • 按模型名、供应商或模型组路由
  • 多 Key 轮换、冷却与熔断
  • 按 Agent、供应商、模型统计用量与费用
Agent Codex++ 供应商池

一行后缀，百万窗口

网关在供应商详情里按模型填窗口（可按公开资料一键填）；直连模式在模型列表里写上窗口后缀，Codex++ 生成独立的 model_catalog_json，让 Codex 按当前模型使用对应窗口。未指定的模型继续沿用供应商级配置。

GETTING STARTED · 快速上手

三步，开整

Codex 功能配合官方 Codex / ChatGPT 桌面应用使用；Claude、Grok 相关功能需安装对应客户端。

01

下载并添加供应商

从 GitHub Releases 下载：Windows 选 *-windows-x64-setup.exe，macOS 选 *-macos-universal.dmg。打开后在「供应商池」填 API Key、登录订阅，或从直连模式导入。

→
02

接入你的 Agent

在「Agent 接入」给 Codex、Claude Code、Grok 打开开关，选默认模型。接入前自动存档配置文件，断开时只还原网关改过的部分。

→
03

启动 Codex

点「启动 Codex」或侧栏 Codex 行的 ▶，增强随之注入；Claude Code、Grok 照常在终端里用。依赖注入的设置改完后需重启 Codex 生效。

不想用网关？直连模式照旧：在「Codex → 旧版供应商配置」里选供应商后启动即可。所有界面增强均可单独关闭。

FAQ · 常见问题

先问，先答

启动后，为什么没有 Codex++ 菜单？

确认是在 Codex++ 界面中点「启动 Codex」打开的官方应用。打开「Codex → 设置」（安装维护在设置页下方）与「关于」页面，检查应用路径、启动状态和诊断日志。macOS 上也可以打开「自动接管官方 App」，自己双击启动官方 App 时由 Codex++ 接管。

切换供应商后，请求为什么失败？

网关模式先在供应商池详情里点「测试」，看状态码、首字耗时和上游错误原文；「用量 → 请求」里失败的请求也会直接显示原因。直连模式在供应商详情中运行模型测试或 Provider Doctor；纯 API 和官方登录 + API 使用不同的认证位置，不要手工复制两种模式的 auth.json。

退出 Codex++ 后，Agent 为什么连不上？

接入网关的 Agent 一直指着本机网关，网关只在 Codex++ 运行时可用，再打开 Codex++ 就恢复。想在退出后用回直连，可在「网关设置」里打开「退出 Codex++ 时恢复直连」（默认关闭）；安装更新前总会先切回直连。

开启原生 Fast 后，为什么仍然看不到开关？

先确认已经保存，并通过 Codex++ 重启 Codex。当前模型还需要声明 Fast 服务等级：直连模式在「Codex → 旧版供应商配置」中打开该模型的配置，设置「Fast（priority）支持」，保存模型与供应商后重启；网关模式下模型组里每个成员都支持 Fast 时，选这个组也能开 Fast。请按供应商实际能力声明；此功能只恢复客户端入口，服务限制与计费仍以供应商为准。

Computer Use 接入后，客户端里为什么没有工具？

接入后需要重启对应客户端才会加载工具；Claude Desktop 退出时会重写自己的配置，建议先完全退出再接入。仍然没有时，在「Computer Use」页的「配置路径与自定义目录」里核对客户端实际读取的目录，并确认已给 ChatGPT 授予辅助功能与屏幕录制权限。目前仅支持 macOS。

增强功能可以关闭吗？官方应用更新后还能用吗？

可以分别关闭，也可以关闭增强总开关。Codex++ 依赖官方桌面应用的页面结构、CDP 和本地数据格式；官方应用更新后，部分功能可能需要跟随适配。修改供应商配置或会话数据前，请保留备份。

配置、会话和日志存在哪里？

设置了 CODEX_HOME 时，Codex 主目录以该变量为准；否则使用 ~/.codex。API Key 只保存在本机，提交反馈前请隐藏密钥与认证信息。
