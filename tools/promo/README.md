# Codex++ 介绍视频

`codex-plus-intro.html` 是一个单文件的动态图形介绍片：1920×1080 画布、7 个场景、总时长 37 秒，
内容全部取自本仓库源码与 README（v1.6.0），不依赖任何外部资源与网络。

以图形为主：内置一套 SVG 图标精灵（`<symbol>` + `<use>`）、架构示意图、环形仪表、
进度条与迷你柱图，文字只留标题与短标签。

## 播放

直接双击打开，或起一个静态服务（浏览器直接打开 `file://` 也可正常播放）：

```bash
npx --yes serve -l 8777 tools/promo
```

打开 `http://127.0.0.1:8777/codex-plus-intro.html`。

## 导出视频

点底部「⏺ 录制并导出视频」：

1. 自动开启全屏并从头播放；
2. 浏览器弹出共享选择框时，选**当前标签页**（对应一整屏舞台画面）；
3. 跑完一轮自动停止，输出 `codex-plus-intro-<时间戳>.webm`。

录制优先走 `getDisplayMedia()`，这样文字与面板都在画面里；若拒绝共享，会退回
`canvas.captureStream()`，此时**只有背景图层会被录进去**，页面会先弹窗确认。

产出为 WebM（VP9，30fps，约 16 Mbps）。需要 MP4 时自行转码：

```bash
ffmpeg -i codex-plus-intro-202610081200.webm -c:v libx264 -crf 18 -pix_fmt yuv420p codex-plus-intro.mp4
```

## 维护

- 版本号、功能名、统计数字都写死在文件末尾的 `TILES` / `STATS` / `ACCENTS` 与各场景文案里。
  仓库结构变动后需要一并更新，改完在浏览器里跑一遍确认。
- 新增场景：加一个 `<section class="scene" data-dur="毫秒" data-name="名称">`，
  场景总数、分段进度条刻度、时间轴都由脚本按 `data-dur` 自动推算。
- 入场动画由 `.scene.active [data-a]` 驱动，用 `--anim` / `--delay` / `--dur` 三个变量控制；
  场景每次进入都会重播，切段和重播不会残留上一段的状态。
- 图标：在文件顶部的 `<svg><symbol>` 精灵里加一条，然后用 `<svg><use href="#i-xxx"/></svg>` 引用。
  **描边属性必须写在 `<symbol>` 上**，`<use>` 落在 shadow DOM 里，外层 CSS 的
  `stroke` / `fill` 传不进去。
