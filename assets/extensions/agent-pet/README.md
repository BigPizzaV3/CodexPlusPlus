# Agent 桌宠

Codex 窗口里可拖动的小角色，随 Codex++ 一起发布的官方拓展包。可以停用，不能删除。

## 两种桌宠

- **简单桌宠**：从图库挑一张图，或者用自己的图片地址。按下压扁、松开回弹，带按压音效。
- **大肥鱼（DeepSeek 鲸鱼）**：原版鲸鱼用量挂件，显示余额、价格与用量统计，带泡泡编辑器、音效库和提醒。

同一时间只显示一个。

## 怎么用

1. 打开右上角的开关启用拓展。
2. 切到「设置」页签挑类型、形象、大小和音效，改动几秒内同步到 Codex，不用重启。
3. 在 Codex 里拖动桌宠换位置，位置会记住。

## 说明

- 图片和可下载的音效在用到时联网下载并缓存在本机，不随 Codex++ 打包。
- 内置图库来自 Microsoft Fluent Emoji（MIT），二次元形象来自 Wikimedia Commons（CC0）。
- 大肥鱼的余额查询由 Codex++ 代为请求，供应商 Key 不会交给拓展页面。

想写自己的桌宠，可以照着这个拓展包的源码（`assets/extensions/agent-pet/`）来写。
