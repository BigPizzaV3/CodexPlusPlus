# Agent 桌宠音效

| 文件 | 音效组 | 用途 |
|---|---|---|
| `Ya1.mp3` | `duck` | 按压 |
| `Ya2.mp3` | `duck` | 松开 |
| `D1.mp3` | `fx1` | 按压 |
| `D2.mp3` | `fx1` | 松开 |

启动器在构建时把这四个文件原样内嵌（`crates/codex-plus-core/src/assets.rs`），以
`window.__CODEX_PLUS_AGENT_PET_SOUNDS__` 注入渲染进程，运行时不下载。
