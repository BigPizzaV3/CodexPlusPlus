# 命名 API Key

普通 API 供应商可保存多个命名 Key。`apiKeys` 保存 ID、名称和密钥，
`activeApiKeyId` 指定当前项；当前项同步到现有 API 配置和认证文件。
旧单 Key 配置自动成为“默认”项，原来的供应商选择方式保持不变。

在供应商详情选择当前项后，点击“保存供应商”。正在使用的供应商沿用
既有保存与重启确认流程；未启用的供应商仅保存快照。聚合供应商继续由成员定义。
添加备用项不会自动切换，最后一项不能通过列表删除。

在 `auth.json` 或 `config.toml` 编辑器中轮换 Key 时，编辑内容同步到当前命名项，
并更新对应的认证文件；保存及重新加载后继续使用新 Key，备用项保持原值。

显式采纳其他 live 供应商身份时，命名 Key 随该身份重新导入。
注入页的设置桥接剥除整个 `apiKeys` 列表，不向用户脚本下发备用密钥。
磁盘凭据沿用上游现有存储方式。
