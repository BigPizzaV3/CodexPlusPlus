# 界面与日常操作

| 入口 | 操作 |
| --- | --- |
| Codex 侧栏 → Codex++ → 界面与日常操作 | 开启「新任务默认 Plan 模式」。空白新任务会切到 Plan，同一草稿里仍可手动改回。 |
| 同上 → 新建项目默认目录 | 输入本机绝对路径并保存。从头创建的新本地项目会放在这个目录下。清空并保存即可恢复桌面默认值。 |
| 同上 → 侧栏显示项目 | 选择要保留的内置入口、项目列表和最近会话。「恢复全部侧栏项目」可以一次恢复。 |
| 同上 → 消息书签 | 开启后，在用户或助手消息的操作栏点击书签。回到设置里的书签列表点「打开」，可回到消息与上下文。摘录保存在本机。 |
| Codex++ 管理器 → 设置 → 通用 → 外观 | 主窗口支持 90%、100%、110%、125%、150% 缩放，可选择紧凑、标准、宽松的列表密度。 |
| Codex 输入框 → 模型菜单 → 列表视图 | 左侧勾选标记表示当前模型，右侧五段价格条支持小数格。悬停可看输入、输出的具体单价。 |
| 管理器 → 皮肤管理 → 本地主题 → 从图片或视频创建 | 选择最多 16 MiB 的本机 MP4 或 WebM，点「应用所选主题」。主界面静音循环播放，切到后台或开启系统减少动态效果时暂停。能播放的编码取决于系统 WebView。 |
| Codex++ 拓展 → 背景图 | 选择静态图片、透明度和铺放方式。见[原生表面与浏览器回归](../scripts/image-overlay-tests.md)。 |
