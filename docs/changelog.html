v1.2.52 最新Latest

2026.08.23

↗

让 Codex++ 管理器与注入体验更稳定、更贴近 Codex 原生界面。A stability-focused release that makes the manager and injected experience feel closer to native Codex.

重点内容Highlights

  • 修复管理页面浅色模式下的主题变量与背景显示问题。Fixed theme variables and background rendering in the manager's light mode.
  • 注入页面跟随 Codex 原生主题，减少深浅色切换时的割裂感。Injected views now follow Codex's native theme for a smoother light/dark transition.
  • 同步桌面运行时、启动器与管理器版本，降低升级后的入口不一致。Synchronized the desktop runtime, launcher, and manager versions to keep upgrades consistent.

v1.2.51

2026.08.23

↗

围绕会话分享、桌面运行时和管理器入口完成一轮功能补齐。A feature-complete update centered on session sharing, the desktop runtime, and manager entry points.

新功能New

  • 支持加密会话分享，分享数据在离开设备前完成保护。Added encrypted session sharing, protecting data before it leaves the device.
  • 管理工具支持通过链接导入会话，并提供重启提示完成加载。The manager can import sessions from a link and guides you through the restart needed to load them.
  • 改进 Codex++ 管理入口与桌面版 CLI 的发现和启动流程。Improved discovery and startup for the Codex++ manager entry and the desktop CLI.

改进与修复Improvements and fixes

  • 优化分享按钮的注入位置与原生菜单的视觉对齐。Aligned the injected share action with the native toolbar and menu styling.
  • 减少会话导入、启动和供应商切换时的边界错误。Reduced edge-case failures during session import, launch, and provider switching.
