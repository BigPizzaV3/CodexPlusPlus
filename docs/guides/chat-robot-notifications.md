# 钉钉和飞书任务通知

在 Codex++ 管理器的「Codex → 远程控制 → 钉钉与飞书通知」中，可以分别配置两个群机器人。Codex 会话完成一轮、出错或出现待审批请求时，机器人向选定的群发送任务状态和会话短编号。

1. 在钉钉或飞书群里添加自定义机器人，复制它的 Webhook。启用了加签就同时复制签名密钥。使用关键词校验时添加 `Codex++`。
2. 在管理器点击对应平台的「配置机器人」，填入 Webhook 和可选密钥，点击「保存」和「测试通知」。确认群里收到测试消息后，打开该平台右侧的开关和页面顶部的「启用远程控制」。管理器运行期间会监听最近有活动的会话。
3. 要在手机上处理审批，打开「允许局域网访问」，在「添加设备」中选择「完全控制」。用手机浏览器配对。手机和电脑使用同一 Wi-Fi 时选择「局域网」，使用同一 Tailscale 网络时选择「Tailscale」。也可以选「仅通知」。
4. 收到等待审批通知后，点「查看并处理请求」，在配对时使用的浏览器核对当前命令或文件变更，再点允许或拒绝。在钉钉或飞书内置浏览器看到配对提示时，可从菜单选择在已配对的系统浏览器打开。

通知链接只包含所选网络上的访问地址和会话 ID。设备权限和每次审批由 Codex++ 远程控制校验。Webhook 和签名密钥保存在本机管理器状态目录，配置界面可更换或清除。更换 Webhook 后，使用新机器人的签名密钥。
