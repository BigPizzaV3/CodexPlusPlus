## 1.7.7

本版汇总 `v1.7.6` 之后合入 main 的全部更新，涵盖聚合供应商拆分（故障转移 / 模型聚合）、官方账号聚合与官方模型列表、Codex 多开、模型列表编辑体验、Claude 汉化 Windows 支持与多项协议稳定性修复。

### 聚合与供应商

- 聚合供应商拆分为两种类型：「故障转移」（多成员共享同一份路由，支持失败切换、轮转与权重策略）与「模型聚合」（把成员模型合并进 Codex 模型目录，选中模型固定发送到对应供应商，可单独开关）。
- 供应商列表拆成 直连 / 需协议转换 / 故障转移 / 模型聚合 四个分页，每页标题带「?」悬浮说明；创建聚合时先选类型、类型严格独立，任一类型下都能继续新建；聚合卡片不再显示轮转策略文案，第三方导入弹层不再被裁断。
- 聚合供应商支持官方登录成员：已完成 ChatGPT 登录的官方账号可加入聚合。运行时解析供应商快照里的 OAuth tokens，临期用 refresh_token 走 auth.openai.com 刷新（与 Codex CLI 同 client_id），轮换结果写回快照，同账号优先采纳 live auth.json 的新凭据，刷新失败加冷却；选中官方成员时转发到 chatgpt.com/backend-api/codex（OAuth Bearer + chatgpt-account-id + originator），401 强制刷新后重试一次，/models 走同一通道。带 URL/Key 的旧 official 模式数据仍按 API 通道，保持兼容。
- 官方登录供应商支持「从上游获取」模型列表：带账号 OAuth 凭据请求 chatgpt.com/backend-api/codex/models，兼容 data/models/items 多种返回形状，跳过官方隐藏模型；纯官方 profile 的编辑器放开「模型列表」区块，用于按模型聚合发布成员模型与逐模型窗口配置。
- 供应商「接入方式」改为三选一：官方登录 / 官方登录 + API / 纯 API，原先的「混入 API KEY」勾选框并入其中。
- 模型列表编辑体验：新增「思考等级」列；「自动压缩」改为下拉组件；模型固定一行一个、没有模型时不显示空行；收窄列最小宽度，窄窗口下不再溢出或截断下拉；聚合成员模型同样一行一个、不再从中间断行。

### Codex 多开

- 新增按供应商身份隔离的 Codex 多开：每个身份使用独立的配置、会话与用户数据目录，可与其他单一 Responses / Chat Completions 供应商同时运行；启动时注入增强脚本，MCP 配置按供应商去重同步。
- 多开管理页支持查看主 Codex 与全部多开实例，可单独重启或结束；支持 Zhipu GLM；入口带 NEW 标记，多开窗口标题带 Codex++ 标识。

### 界面与交互

- Claude 汉化页重新排版：去掉实现方式板块、修正图标位置、放大标题与数据卡间距，数据卡改为两列布局。
- 修复 MCP 启用状态未同步到 live 配置；管理页填满窗口并恢复列表滚动。
- 插件市场文案「CodeX」统一为「Codex」。
- 活动悬浮层支持镜像到右侧显示。

### Claude 汉化

- 新增 Windows 支持：为官方 Claude 创建受管 MSIX 副本并在启动时注入中文界面，官方应用与 app.asar 保持原样；修复 MSIX 副本注入与识别。

### 增强与协议

- 恢复「强制中文界面」增强（默认关闭，需手动勾选）：通过 Codex 原生 `localeOverride` 设置强制 zh-CN，并补上 navigator 语言与 Statsig 语言包开关，避免 Statsig/VPN 不通时回退英文；关闭时只回滚自己写过的值，不覆盖用户后来手动选择的语言。
- 新增「容量错误自动重试」增强（默认关闭）：模型容量不足（如 `Selected model is at capacity. Please try a different model.`）时自动点会话里的「重试」，直到成功或达到次数上限；重试间隔默认 0 秒、次数上限默认 15，可在 Codex++ 设置里调整。
- 修复 Codex 客户端可能一直停在启动画面（只有居中 logo、侧边栏与输入框都不出现）：macOS 启动器给单次探测失败加宽限，不再把一次失败当成「Codex 已退出」；渲染侧补上启动壳自救，页面挂载后长时间长不出主界面时自动刷新一次（限次并冷却）。
- 移除「渠道保护」：删除供应商编辑页的错误冷却、同渠道队列与 RPM 预留配置，协议代理不再做渠道排队、限速和错误冷却自动重试；旧 `settings.json` 里的同名字段会被忽略。
- Chat 路由明确拒绝服务端原生搜索：返回 `unsupported_native_web_search`，提示使用客户端搜索工具或支持原生搜索的 Responses 上游，不再静默忽略。
- 上游 web_search 调用缺少查询参数时标记为失败，不执行空搜索；web_search 参数兼容 `input` 字段。
- 修复 macOS 更新器在不规范安装路径下的识别：路径按大小写与分隔符归一化。
- 语音设置兼容早期 SenseVoice 保存：旧版只写入 `local://sensevoice` 而缺 provider 字段时，加载时自动恢复离线标记，不再被按 HTTP 地址校验报错。
