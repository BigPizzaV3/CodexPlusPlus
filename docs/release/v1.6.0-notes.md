## 1.6.0

本次更新主要改进语音输入、增强配置、供应商编辑和皮肤管理。

### 新功能

- **API Key 语音输入**：在「Codex增强 → 语音输入」中配置独立的 OpenAI 兼容转写服务。支持录音后插入文字、停止并发送、重试和取消；语音服务 Key 与编码供应商 Key 分开配置。
- **AI Agent 缓存清理**：新增独立页面，提供扫描、选择与清理入口。

### 界面改进

- Codex 增强按「常用增强」「语音输入」「下一步建议」分标签展示，统一总开关和保存入口，不再区分兼容与完整增强模式。
- 供应商编辑页默认展示名称、接入模式、URL、Key 和上游协议，其余配置与预览按需展开；上游协议改为下拉框，渠道保护和更多选项统一折叠布局。
- 皮肤管理默认展示「我的主题」，增加名称搜索；保存、应用和恢复操作集中展示，区分当前配置、编辑草稿和待应用状态。
- 皮肤编辑按图片、文字、配色分组，诊断和授权说明默认折叠；照片设置支持自动换行，修复右侧控件溢出。
- 移除管理工具顶部的全局刷新按钮，各页面保留对应刷新入口。

### 功能调整

- 撤下远程 Zed、Upstream worktree 适配器、强制中文和原生菜单汉化。原生 SSH、worktree 和会话分享能力继续保留。

### 安装包

- macOS：通用 DMG，同时支持 Intel 与 Apple Silicon，沿用 Developer ID 签名和 Apple 公证流程。
- Windows：x64 安装程序和便携 ZIP。

安装包由 GitHub Actions 构建完成后自动添加到本 Release。
