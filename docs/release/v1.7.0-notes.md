## 1.7.0

本版汇总 `v1.6.0` 之后合入 main 的全部更新，涵盖界面与工作区、插件市场、供应商与桥接、用量挂件及安装更新。

### 界面与工作区

- 新增 Agent 图标栏，优化 Codex / Grok 切换与工作区导航，统一管理工具的原生界面样式。
- 新增持久弹性自定义布局：拖动面板时其他区域自动让位，支持边缘吸附、可拖动侧边栏及下次打开恢复。
- 新增 Power Mode 打字特效，包含输入法组字、退格和减少动态效果的兼容处理。
- 改进推荐赞助横幅轮播，更新首页截图、功能介绍、社区入口与赞助信息，并保留原有赞助项目。

### 插件、供应商与桥接

- 新增按需加载的 CodeX 插件市场与单包操作，避免为浏览目录而批量加载所有插件。
- 新增用户脚本总开关，调整脚本加载与重载行为。
- 修复官方登录配置保留、供应商配置应用及导入、模型清单的本地/远端来源识别等问题；远程会话删除只走对应原生宿主，不退回本地删除。
- 协议代理与转换继续透传客户端会话请求头，改进渠道请求限制的配置说明。
- 限制请求准备阶段的读取与等待时间，修复客户端捕获超时恢复及调试连接识别，减少不必要的重注入或重启。

### 完整鲸鱼用量挂件

- 默认关闭，可在「Codex增强 → 常用增强 → 挂件与桌宠」开启。包含原版角色交互、模块化泡泡编辑器、点击序列、加权随机文字/图片、模块库、角色/GIF 图库、四边吸附、翻转、滚动条避让、右键和长按菜单。
- 内置六个原版音效，支持导入、试听、波形裁剪与自定义音效组；按压、松开、完成、提问和授权提示可分别配置。
- 提供会话与全机用量、今日/近7天/本月/累计统计、历史分页与搜索、订阅窗口快照，以及按用户配置单价和汇率计算的本机费用估算。
- 包含34个固定版本供应商模板、余额/额度查询与探活；复用已保存的供应商凭据，不在挂件中另存 API Key。
- 账户每日账本分别记录扣费与到账，支持余额校正、历史账户识别和 revision 冲突保护；本机估算与账户观测分别展示。
- 修复宿主样式使声音勾选框和滑轨不可见的问题，明确声音总开关；内嵌音频直接读取字节，兼容页面安全策略。
- 隐藏、关闭、切供应商及重复注入时释放界面与音频资源；关闭本机统计后停止读日志，远程会话不借用同 ID 本地记录。

功能与完整界面引擎来源：[MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)；Codex 桌面版技术路线参考：[Yang-huai406/Codex-Whale-Public](https://github.com/Yang-huai406/Codex-Whale-Public)。原始代码和素材声明随项目保留。

### 安装、更新与兼容性

- 改进 macOS 更新事务：先准备完整应用，再替换；失败时回滚，并保留已有应用安装。
- 保留用户已删除的 Windows 桌面快捷方式选择，修复安装器 CRLF 兼容检查；发布流水线重试并实际验证 NSIS 安装。
- 将皮肤包兼容性与产品版本分开判断。
- 更新语音输入的后端加载器兼容测试、界面测试及审查记录。

### 使用与下载

鲸鱼声音会保留旧版偏好。需要声音时，在「全局设置」勾选「声音总开关与按压音效」，选择事件音效后试听并保存。

没有真实数据、尚未完成扫描或未配置价格时显示未知，不当作零消费或完整账单。使用说明与素材来源见 [挂件说明](https://github.com/BigPizzaV3/CodexPlusPlus/blob/v1.7.0/docs/whale-widget.md) 和 [功能验收](https://github.com/BigPizzaV3/CodexPlusPlus/blob/v1.7.0/docs/whale-parity.md)。

- Windows：x64 安装程序与便携 ZIP。
- macOS：同时支持 Intel 与 Apple Silicon 的通用 DMG，沿用 Developer ID 签名与 Apple 公证流程。

安装包由 GitHub Actions 构建完成后添加到本 Release。查看 [v1.6.0 到 v1.7.0 的全部提交](https://github.com/BigPizzaV3/CodexPlusPlus/compare/v1.6.0...v1.7.0)。
