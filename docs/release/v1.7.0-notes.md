## 1.7.0

新增 Codex 内置完整鲸鱼用量挂件，默认关闭，可在「Codex增强 → 常用增强 → 挂件与桌宠」开启。

### 鲸鱼挂件

- 保留参考项目的完整界面与角色交互：模块化泡泡编辑器、点击序列、加权随机文字/图片、模块库、角色/GIF 图库、四边吸附、翻转、滚动条避让、右键和长按菜单。
- 内置六个原版音效，支持音频导入、试听、波形裁剪与自定义音效组；按压、松开、完成、提问和授权提示可分别配置。
- 提供当前会话与全机用量、今日/近7天/本月/累计统计、历史分页与搜索、订阅窗口快照，以及按用户配置单价和汇率计算的本机费用估算。
- 包含34个固定版本供应商模板、余额/额度查询与探活；复用 Codex++ 已保存的供应商凭据，不在挂件中另存 API Key。
- 账户每日账本将扣费和到账分开记录，支持余额校正与多窗口 revision 冲突保护；本机费用估算与账户余额观测分别展示。

### 修复与兼容

- 修复宿主样式使声音勾选框和滑轨不可见的问题，明确标注声音总开关；静音时试听提供提示。
- 内嵌音频直接读取字节，避免 `fetch(data:)` 受宿主安全策略限制。
- 修复 CDP 分块响应及 ChatGPT/空标题导致的调试连接误判，减少不必要的重启。
- 隐藏、关闭、切供应商和重复注入时清理节点、监听、定时器、观察器与音频上下文；关闭本机统计后停止读取日志，远程会话不借用同 ID 本地记录。

### 使用与安装包

声音默认状态会保留旧版偏好。需要声音时，在鲸鱼「全局设置」勾选「声音总开关与按压音效」，选择事件音效后试听并保存。

数据缺失、尚未完成扫描或未配置价格时显示未知，不将其当作零消费或完整账单。使用说明与素材来源见 [挂件说明](https://github.com/BigPizzaV3/CodexPlusPlus/blob/v1.7.0/docs/whale-widget.md) 和 [功能验收](https://github.com/BigPizzaV3/CodexPlusPlus/blob/v1.7.0/docs/whale-parity.md)。原始素材声明随项目保留。

Windows：x64 安装程序与便携 ZIP。macOS：同时支持 Intel 与 Apple Silicon 的通用 DMG，沿用 Developer ID 签名与 Apple 公证流程。安装包由 GitHub Actions 构建完成后自动添加到本 Release。
