## Codex++ v1.5.0

自 v1.4.0（2026-09-28）以来累积 **69 个提交**（含并合共 82 个），其中 12 项新功能、42 项修复。

---

### 新增功能

**适配新版 Codex 导航图标栏，Codex++ 页面重构**

新版 Codex 在最左侧新增了导航图标栏（navigation rail），原侧边栏入口依赖的
`nav[role="navigation"]` 失效——Codex++ 的入口在新版上会静默消失。现已改挂到
`nav[data-app-navigation-rail]`，并 clone 原生按钮取得一致的样式与提示。

同时把页面形态对齐 Codex 原生的「图标栏 + 左面板 + 内容区」三段式：

- 用户脚本从 Codex++ 弹窗拆出，成为独立的「拓展」全屏页面
- 页面新增左面板，「拓展」页列脚本分组，不再需要先开弹窗再切 tab
- 页面跟随 Codex 的界面缩放与深浅色主题，配色字号改用宿主令牌
- 「推荐内容」独立成入口，改为网格卡片

**拓展接口：向用户脚本开放 UI 能力**

第三方用户脚本现在可以通过 `window.codexPlus` 调用 Codex++ 的界面能力，不再只能自己改 DOM：

- `registerRowAction` —— 会话行「更多操作」加菜单项
- `registerPage` —— 注册整页视图（自动配图标栏入口）
- `registerMenuItem` —— Codex++ 菜单里加开关或按钮
- `toast` —— 右下角提示，支持 info/success/warn/error 四类配色
- `call` —— 调用白名单内的后端能力

接口带版本号、路由白名单、注册配额与失败隔离，开发指南见仓库根目录 `EXTENSIONS.md`。

**按模型粒度的元数据统一 (#2279)**

`[1M]` 后缀语法全链路适配，模型上下文窗口与自动压缩阈值可逐模型配置。内置元数据命中时自动回填空窗口与压缩列，与内置全字段一致时不写自定义配置。

**渠道保护**

按供应商配置的请求节流与冷却：请求排队、滑动窗口限流、命中 `Retry-After` 时进入冷却，冷却结束后自动恢复被中断的请求。冷却状态与限流可在供应商设置里单独配置。

### 重要修复

**会话恢复**

- WSL 模式下删除会话现在会真正删除 rollout 文件 (#162)
- 恢复原生会话中缺失的用户消息，支持自动复查（间隔 30 分钟）
- 完善恢复的证据校验、锁释放与异常报告；来源变化时回滚写入并说明中止原因

**压缩协议**

- 透传 Responses 原生压缩协议，修复第三方模型压缩失败
- 兼容无增量摘要的流量，修正压缩项 ID 前缀与完整输出事件

**注入与样式**

- 修复额度横幅在输入框与侧边栏的闪烁（CSS 预隐藏规则）
- 修复 dream-skin 的 `top-fade` 选择器误伤对话容器，导致对话窗口与输入框整体消失
- 修复混合 Key 场景下的额度处理与输入框恢复
- 修复官方用量生命周期改动未同步进分片的问题

**模型与中转**

- 中转站模型名统一 sanitize，阻断被污染模型名的转义放大循环
- 修复服务等级 Fast 档位缺失 gpt-6 系列模型
- 修复元数据 key 归一化与前端不一致（同名变体后写者胜）

**其它**

- 修复新版 Codex 图标栏上原生选中态与 Codex++ 选中态同时高亮
- 修复 Codex++ 页面并排多出一列（改为顶替原生侧边栏）
- 补齐 Windows 下按当前 CUA 运行时识别浏览器
