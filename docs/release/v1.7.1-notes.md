## 1.7.1

本版修复 v1.7.0 的界面与启动问题，并恢复原生面板布局。

### 界面与交互

- 移除自由拖动、磁吸、弹性让位及布局记忆功能，避免拖动后侧边栏、对话区和输入框塌陷。旧布局配置不再启用该功能；更新后请完整重启 Codex++。
- 移除重复的商店导航按钮，保留原生「插件」入口及插件市场能力。
- 新增「分享会话按钮」显示开关，修正安装位置与关闭后的清理，避免误挂到 review、浏览器或终端面板。
- 供应商编辑页首次默认展开模型配置，记住各分组展开状态；新出现的校验错误会展开对应分组。
- 将对话居中宽度调整限定在当前会话正文与输入区，排除侧边栏、工具面板和布局祖先，并在目标失效时恢复原样式。
- 修复会话删除菜单的状态刷新，以及原生插件导航、插件安装与卸载状态同步。

### 启动与协议

- 改进 Windows Store 启动后的实际进程识别、调试连接短暂中断的处理与退出终态记录。
- 修复调试桥接等待响应时丢失事件及连续消息处理，保留正在进行的绑定请求。
- 协议转换遇到不能安全转换的加密内容时给出明确错误，避免静默丢弃。
- 补充 Kimi 网关拒绝 `thinking type: adaptive` 时的纯标准协议提示与回归覆盖。

### 下载

- macOS：Intel 与 Apple Silicon 通用 DMG，包含 Developer ID 签名和 Apple 公证票据。
