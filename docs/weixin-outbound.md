# 微信工作区附件回传

微信会话可通过媒体模块向当前联系人回传工作区中的图片和文件。

## 开启与关闭

设置项 `weixinConnectAllowOutboundAttachments` 默认为 `false`，旧配置缺少该字段时保持关闭。填写明确的允许发送方 ID 和工作目录后，才能开启回传；空白名单和 `*` 不可用于回传授权。

开启后新建的微信会话注册 `weixin_send_attachment`，模型通过 `path` 与 `kind=image|file` 回传结果。关闭时不为新会话注册工具，已注册线程中的残留调用也会被服务端拒绝。保存关闭、联系人名单或工作目录变化后，当前回合授权失效，并取消尚未完成的发送；重新开启不恢复旧授权或旧成功缓存。停止连接和修改连接账号也会撤销旧授权。

已被远端接收的数据无法撤回；取消在途 HTTP 不能证明远端未接收。网络错误的重复调用沿用该回合的失败结果，不自动重复上传。

只有开启回传或修改允许发送方、工作目录时才校验回传配置。已保存目录后来失效时，仍能保存其他设置和启动文字连接；状态提示附件暂不可用，附件工具拒绝发送。不存在的工作目录临时回退到管理器状态目录下独立的文字工作区，不自动重建原目录，也不允许从该状态目录回传文件；目录恢复后下一条消息重新使用原工作区。

## 文件与调用边界

仅回传当前显式工作区中的普通文件，每个文件最多 100 MiB，每回合最多尝试 10 次。拒绝空、根、home 及其祖先工作区；拒绝 Codex、管理器状态目录和敏感路径组件，包括 `.codex`、`.git`、`.ssh`、`.aws`、`.env*`、认证及私钥文件。自定义 `CODEX_HOME`、`CODEX_SQLITE_HOME`、管理器 state 和 Electron user-data 目录也不可外发。

路径解析后核验实际打开的句柄及文件身份，以同一文件句柄完成有界读取，并在读取前后核验路径、大小、修改时间和身份。拒绝越界链接、敏感路径别名和多硬链接文件；工作区目录身份变化同样撤销授权。上传内容由已核验的内存快照生成，后续不按路径重新打开文件。

接收方及微信 context token 由当前入站消息绑定，不接受模型指定接收方。每次调用检查当前授权、联系人、线程、回合、调用 ID、工具名、命名空间与参数。缓存仅属于一个联系人和回合；同一调用 ID 使用不同参数会被拒绝，关闭后的旧成功结果不会复用。

## 旧线程恢复

恢复旧线程不追加动态工具、不静默迁移历史。旧线程缺少附件工具时，在微信发送 `/reset-attachments` 明确重置当前联系人的微信线程映射，再发下一条请求。仅在当前联系人具有有效回传授权时执行；原线程历史保留，其他联系人不受影响。原线程恢复失败时仍保留上游的新建线程兜底。

## 验证范围

普通 Rust 定向测试覆盖权限、文件边界、调用缓存及本地 HTTP/stdio 协议。测试使用虚构凭据及本地模拟端点，不代表真实微信收发或另存内容一致性验收。真实微信客户端版本、文件类型及实际字节数、另存内容与取消后的远端状态需在最终组合 head 单独记录。
