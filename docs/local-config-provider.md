# 本机配置供应商

管理器首次读取设置时，将当前 `CODEX_HOME` 的 `config.toml` 和 `auth.json`
保存为普通可编辑的“系统默认”供应商。已有供应商选择和开关保持不变，
不会在导入时写入本机配置。后续编辑、重命名或删除该快照后不重复导入。

导入复用现有配置回填和身份校验；本机配置已经指向托管协议代理时，
从当前供应商恢复真实上游，避免把代理自身保存为上游。
当前供应商为聚合时，同时复制聚合定义并关联到快照的新 ID，保留成员权重、
路由、默认成员及模型聚合设置；切换回该快照时继续使用协议代理。
官方登录和 API 配置都通过现有供应商切换流程应用。

配置损坏或导入期间身份变化时保留原设置，管理器报告读取失败。
回归仅使用临时目录，不修改正在使用的 Codex 配置：

```sh
cargo test -p codex-plus-core --test local_config_provider
```
